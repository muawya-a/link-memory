## Git history

The source working tree available for this preparation did not contain Git history. This repository therefore begins with a clean snapshot commit dated 2026-09-30. The commit date records when this snapshot was placed under Git; it does not claim that the project was first created on that date or reconstruct earlier authorship and change dates.

Future changes should be committed with the owner's GitHub-associated noreply email and signed with a key registered to that account when available. GitHub's attribution and signature verification provide stronger public provenance after the owner pushes the commits.
